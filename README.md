# Gestion-de-restaurante
Es una aplicación web desarrollada para administrar diferentes actividades de un restaurante desde un solo sistema. El proyecto permite manejar información relacionada con clientes, empleados, usuarios, mesas, reservas, pedidos y productos. También cuenta con funciones como inicio de sesión y generación de tickets.

El sistema está desarrollado principalmente con Java y Spring Boot, utilizando HTML, CSS, JavaScript y Thymeleaf para las interfaces, y MySQL para almacenar la información.
